# Movie Night 🎬

Movie Night is a simple movie discovery website I built using HTML, CSS, and JavaScript.

I made this project as part of my learning journey in web development. I wanted to build something a little more interactive than my first project and practice working with JavaScript, dynamic content, and responsive design.

## Features

- Browse a collection of movies
- Search movies by title
- Filter movies by genre
- Sort movies by rating
- View more details about a movie
- Mark movies as favorites
- Switch between light and dark mode
- Responsive design for different screen sizes

## Technologies Used

- HTML
- CSS
- JavaScript
- Git & GitHub
- GitHub Pages

## What I Learned

While building this project, I learnedd:

- Creating and styling responsive layouts
- Using JS to dynamically display content
- Working with arrays + objects
- Filtering + sorting data
- Handling user interactions + events
- Creating a simple popup/modal
- Using GitHub for version control and deployment
